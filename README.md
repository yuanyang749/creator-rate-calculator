# Creator Rate Calculator · 商单报价计算器

免费、开源、纯前端（HTML + CSS + JavaScript）的创作者商单报价估算工具。

## 功能

- 根据平均原创曝光、商业帖曝光系数、受众匹配和自定义 CPM 估算发布价值
- 根据策划写作、实际测试、录屏、原创配图和剪辑工时估算制作成本
- 支持直接成本（实报实销，不参与比例加价）、额外修改、二次使用授权、竞品排他、加急交付、置顶附加费
- 输出建议开价、目标成交价和**仅供内部参考**的底价，并支持一键切换「对外报价模式」隐藏内部底价与成本拆解
- 支持固定稿酬、固定费用加佣金、纯效果佣金三种结算模式
- CPA / CPS 转化情景测算，纯效果模式显示达到目标费用所需的有效转化数
- 复制对外报价文案、复制内部测算报告、打印或保存为 PDF
- 不上传数据、不调用接口、不持久化保存输入

## 运行与部署

在浏览器中打开 `index.html` 即可。

如果使用本资料包上传 GitHub，请将 GitHub Pages 发布目录设置为 `/docs`。如果单独新建计算器仓库，则把这个文件夹里的 `index.html`、`styles.css`、`app.js`、`LICENSE` 和 `README.md` 放在仓库根目录，Pages 目录设置成 `/(root)`。

## 公式

```text
商业帖预估曝光 = 普通原创平均曝光 × 商业帖曝光系数
发布流量估值 = 商业帖预估曝光 / 1000 × 自定义 CPM × 受众匹配系数
人工制作费 = （基础工时 + 已勾选的额外工序工时）× 时薪 + 额外修改费
内容制作成本 = 人工制作费 + 直接成本
附加费用 = （发布流量估值 + 人工制作费）× 授权 / 排他 / 加急比例 + 置顶费用
基础估值 = 发布流量估值 + 内容制作成本 + 附加费用
建议开价 = 基础估值 × (1 + 开价溢价比例)
目标成交价 = 基础估值
内部底价 = 基础估值 × (1 - 内部底价折让比例)
```

常规报价结果（基础估值 ≥ 300 元）四舍五入到 50 元档位，小额试单（< 300 元）按 10 元档位取整；参数可自主调整。不同平台和行业需要分别校准，工具默认值是示例而非经过验证的市场均价。

## 结算术语

- **固定稿酬**：完成约定内容并发布后支付固定费用。
- **CPA**：按明确约定的有效行为支付佣金，可能是注册、认证或其他行为；要明确有效性判定规则。
- **CPS**：按实际成交或销售额支付佣金；要明确归因规则与退款处理。

纯效果付费没有固定保障收入。商家需要以书面形式明确交付、审核与修改、支付时间、有效转化条件、归因和授权范围。

## 隐私

本工具不包含外部脚本、分析 SDK、Cookie、Local Storage、后端或网络请求。所有输入仅在浏览器当次打开页面时使用。
